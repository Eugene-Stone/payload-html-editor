# Changelog

All notable changes to this project are documented here.

## [0.1.5] - 2026-11-20

### Added
- Add the `toolbar-is-sticky` class to the editor while its toolbar is sticky at the 56px top offset.
- Format HTML source with line breaks and indentation when opening the source editor.

### Changed
- Make toolbar SVG icons inherit the editor text color.

## [0.1.4] - 2026-10-12

### Added
- Add a demo preview and video link to the README.

## [0.1.3] - 2026-10-12

### Added
- Support linking images inserted in the editor and preserve image links in HTML.

### Changed
- Prevent links from navigating when clicked inside the visual editor.
- Keep the main toolbar above editor controls while scrolling.

## [0.1.2] - 2026-10-09

### Added
- Add image alt-text editing and group image upload and media-library actions in the toolbar.
- Add a sticky toolbar for table editing.

### Changed
- Refresh the toolbar with SVG icons and a text-alignment selector.
- Document peer dependencies and setup guidance in the README.

## [0.1.1] - 2026-10-09

### Changed
- Expand the README with feature options, media collection requirements, compatibility, and security guidance.

## [0.1.0] - 2026-10-09

### Added
- Initial release of the Payload CMS 3 HTML editor field, with Tiptap editing, formatting and table controls, image upload and media-library integration, and an HTML source editor.
